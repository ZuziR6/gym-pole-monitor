# Simulação no Tinkercad

A primeira etapa do projeto foi realizada no Tinkercad, com o objetivo de montar e validar o circuito antes da implementação em hardware físico.

### Componentes utilizados

* Arduino Uno R3
* Protoboard
* Sensor ultrassônico HC-SR04
* LED RGB
* LED vermelho
* Botão
* Resistores

### Montagem inicial

O circuito foi configurado para representar uma estação de polia de academia.

O sensor ultrassônico será utilizado para detectar a presença de uma pessoa na estação, enquanto os LEDs indicarão seu estado:

* 🟢 Verde: estação disponível
* 🔴 Vermelho: estação ocupada
* 🔵 Azul: estação em manutenção

O botão será utilizado para simular a ativação do modo de manutenção.
